# Amazon Account Gen — Design Spec
*2026-04-09*

## Overview

Two-phase automated tool for creating Amazon accounts at scale using Playwright (CDP-based). Runs as a standalone Node.js CLI separate from the ScalpBot price/news pipeline.

**Phase 1 (`--setup`):** Builds a reusable Google Voice number pool. Runs headed, one at a time, babysit-friendly.

**Phase 2 (`--gen`):** Creates Amazon accounts concurrently using the GV pool. Runs headless, 5-10 parallel contexts.

---

## File Structure

```
amazon-gen/
  index.js            — entry point, routes --setup vs --gen flags
  config.js           — all settings: domains, concurrency, proxy mode, IMAP creds, SMSPool key
  profiles.js         — loads profiles.csv, picks next unused card row
  imap.js             — polls Gmail IMAP for OTP codes (email OTP + GV-forwarded SMS OTP)
  google-setup.js     — Phase 1: creates Google account + claims GV number + enables SMS forwarding
  amazon-worker.js    — Phase 2: single Amazon account creation flow
  output.js           — appends completed account to accounts.txt
  gv-pool.json        — persisted GV number pool (auto-generated, gitignored)
  proxies.txt         — one proxy per line: host:port:user:pass (gitignored)
  profiles.csv        — input: cardNumber,cvv (gitignored)
  accounts.txt        — output: append-only credentials log (gitignored)
```

## Input Format (`profiles.csv`)

Generated by Gemini (Capital One Eno VCCs). One card per Amazon account.

```csv
cardNumber,cvv
4111111111111111,123
4222222222222222,456
```

## Auto-Generated Per Account

| Field | Method |
|---|---|
| Account email | `randomword+digits@` one of 7 domains, round-robin |
| Account password | Pattern: `Word+3digits+symbol` (e.g. `River847!`) |
| Shipping name | Random first + last from built-in ~200 US name pool |
| Shipping address | Jigged billing address — randomizes suffix (`Dr`/`Drive`/`Dr.`), optionally appends `Apt N` or `Unit X`, city/state/zip fixed |
| Billing address | Hardcoded: Tylere Hommel, 43007 Lemonwood Dr, Lancaster CA 93536 |

## Phase 1 Flow — `--setup` (headed, sequential)

Builds `gv-pool.json`. Run once to create your GV number pool.

For each GV number to create:
1. Open headed Chrome
2. Navigate to `accounts.google.com/signup`
3. Fill name (random), generate Gmail address, password from config pattern
4. Call SMSPool API → buy number → poll for Google SMS OTP → enter code
5. Navigate to `voice.google.com` → claim a US GV number
6. Settings → Forwarding → enable "Forward messages to email" → enter the Gmail just created
7. Append to `gv-pool.json`:
```json
{ "gvNumber": "+16615550101", "gmailAddress": "...", "gmailPassword": "...", "available": true }
```

---

## Phase 2 Flow — `--gen` (headless, concurrent)

Runs N workers in parallel via `Promise.all`. Each worker:

1. Lock next unused profile row from `profiles.csv`
2. Lock an `available: true` GV number from `gv-pool.json` (mark `available: false`)
3. Generate random email, password, shipping name, jigged shipping address
4. Open Playwright browser context — apply proxy if `proxyMode: 'proxy'`
5. Navigate `amazon.com/ap/register` → fill name, email, password → submit
6. **Email OTP:** IMAP poll Gmail catch-all for Amazon verification email → extract 6-digit code → enter
7. **Phone verification:** Enter GV number → IMAP poll for forwarded SMS → extract code → enter
8. **2FA setup:** Navigate to Amazon 2FA → select authenticator app → click "Can't scan barcode" → scrape secret key
9. Add billing address + card from profile row
10. Mark GV number `available: true` (reusable for next account)
11. Append to `accounts.txt`

## Output (`accounts.txt`)

Append-only. Every run adds to the same file — never overwrites.

```
email|password|2FA_secret|gv_number|card_last4|shipping_name|shipping_address|created_at
```

Example:
```
james.r492@asdsws.xyz|River847!|JBSWY3DPEHPK3PXP|+16615550101|1111|Marcus Webb|43007 Lemonwood Drive Apt 3 Lancaster CA 93536|2026-04-09T11:23:00Z
```

---

## Proxy Handling

- `proxyMode: 'direct'` — no proxy, uses whatever network the machine is on (home ISP or hotspot)
- `proxyMode: 'proxy'` — reads `proxies.txt`, assigns one proxy per Playwright browser context, rotates through list

`proxies.txt` format:
```
host:port:user:pass
host:port:user:pass
```

---

## Security

The following are added to `.gitignore` and never committed:
- `amazon-gen/profiles.csv`
- `amazon-gen/accounts.txt`
- `amazon-gen/gv-pool.json`
- `amazon-gen/proxies.txt`

---

## Dependencies

- `playwright` — browser automation (CDP-based)
- `imap` — IMAP email polling
- `mailparser` — parse email bodies to extract OTP codes

All other logic uses Node.js built-ins (`fs`, `https`, `crypto`).

---

## CLI Usage

```bash
# Build GV pool (run once, headed, babysit if needed)
node amazon-gen/index.js --setup

# Generate Amazon accounts (headless, concurrent)
node amazon-gen/index.js --gen

# Generate with explicit concurrency override
node amazon-gen/index.js --gen --concurrency 8
```
